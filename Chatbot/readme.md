# Simple Explanation

## What is a Chatbot?

A chatbot is a program that talks with users and gives automatic replies.

---

# How This Code Works

## Step 1

Program takes input from user:

```python id="j0x2qx"
input()
```

---

## Step 2

It checks the message using:

```python id="f1brdv"
if-elif
```

---

## Step 3

Bot gives reply based on user message.

Example:

```text id="rk0krq"
If user types "price"
Bot shows product price
```

---

## Step 4

Loop runs continuously until user types:

```text id="pq2wqn"
bye
```

# Concepts Used

| Concept    | Purpose                  |
| ---------- | ------------------------ |
| while loop | Run chatbot continuously |
| input()    | Take user message        |
| if-elif    | Check user query         |
| print()    | Display bot reply        |
