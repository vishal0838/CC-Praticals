### **Unit I: Introduction to Cloud Computing & Service Models**

**Q1: What are the 5 essential characteristics of Cloud Computing?** **A:** According to NIST, they are: On-demand self-service, Broad network access, Resource pooling, Rapid elasticity, and Measured service.

**Q2: Differentiate between IaaS, PaaS, and SaaS.** **A:** * **IaaS (Infrastructure as a Service):** Provides raw computing resources like VMs, storage, and networks (e.g., Amazon EC2).

* **PaaS (Platform as a Service):** Provides a platform/environment for developers to build and deploy applications (e.g., Google App Engine).
* **SaaS (Software as a Service):** Provides fully functional, end-user software applications over the internet (e.g., Google Workspace, Microsoft 365).

**Q3: Name the steps in the Seven-step model of cloud migration.** **A:** 1. Assessment, 2. Isolation, 3. Mapping, 4. Migration, 5. Testing, 6. Optimization, and 7. Governance/Maintenance.

**Q4: What are the four main Cloud Deployment Models?** **A:** Public Cloud, Private Cloud, Hybrid Cloud, and Community Cloud.

### **Unit II: Data Storage and Cloud Computing**

**Q5: Distinguish between NAS (Network Attached Storage) and SAN (Storage Area Network).** **A:** NAS is a file-level storage architecture attached to a standard network using protocols like NFS or NFS/SMB. SAN is a highly secure, dedicated high-speed network that provides block-level data storage access.

**Q6: What is Direct Attached Storage (DAS)?** **A:** DAS is digital storage directly connected to the computer/server accessing it, without going through a network (e.g., internal hard drives or external USB drives).

**Q7: What does "Storage Provisioning" mean in the cloud?** **A:** It is the process of allocating and assigning cloud storage space to users or applications based on their current operational requirements.

---

### **Unit III: Virtualization in Cloud Computing**

**Q8: Define Virtualization and state its primary goal.** **A:** Virtualization is the technology that allows you to create multiple simulated environments or dedicated resources from a single, physical hardware system. Its primary goal is to maximize physical resource utilization.

**Q9: What is the role of a Hypervisor (VMM)?** **A:** A Hypervisor or Virtual Machine Monitor is software that creates, runs, and manages Virtual Machines (VMs) by abstracting and distributing the underlying physical hardware resources.

**Q10: Explain the difference between Full Virtualization and Paravirtualization.** **A:** In **Full Virtualization** (e.g., VMware), the guest OS is completely unaware it is virtualized and requires no modifications. In **Paravirtualization** (e.g., Xen), the guest OS is modified to communicate directly with the hypervisor via hypercalls, improving performance.

---

### **Unit IV: Cloud Platforms and Cloud Applications**

**Q11: What is Amazon EC2?** **A:** Amazon Elastic Compute Cloud (EC2) is an IaaS web service that provides secure, resizable compute capacity (Virtual Machines called "instances") in the AWS cloud.

**Q12: What is the primary difference between Amazon SimpleDB and DynamoDB?** **A:** SimpleDB is designed for smaller datasets with low request rates and has a storage limit per domain (10 GB). DynamoDB is a highly scalable, fully managed NoSQL database built for massive scale, offering consistent single-digit millisecond latency.

**Q13: Give an example of a cloud-based business application and a scientific application from your syllabus.** **A:** * **Business Application:** CRM (Customer Relationship Management) or ERP (Enterprise Resource Planning) systems.

* **Scientific Application:** Protein Structure Prediction (Biology) or Satellite Image Processing (Geosciences).

**Q14: What is OpenStack?** **A:** OpenStack is a free, open-source software platform standardly deployed as an Infrastructure as a Service (IaaS) to build and manage public and private cloud infrastructure.

---

### **Unit V: Security in Cloud Computing**

**Q15: Explain the CIA Triad in the context of Cloud Security.** **A:** * **Confidentiality:** Ensuring sensitive cloud data is accessed only by authorized users.

* **Integrity:** Ensuring data cannot be modified in transit or at rest by unauthorized parties.
* **Availability:** Ensuring cloud resources and applications are reliable and accessible to authorized users when needed.

**Q16: What is a "Cloud Digital Persona"?** **A:** It refers to the aggregated online identity, credentials, access privileges, and digital footprints associated with an individual user or entity interacting with cloud services.

**Q17: What is Acunetix?** **A:** Acunetix is an automated web application and cloud security scanning tool used to detect vulnerabilities like SQL Injection, Cross-Site Scripting (XSS), and misconfigurations.

---

### **Unit VI: Advanced Techniques in Cloud Computing**

**Q18: Differentiate between Distributed Cloud Computing and Edge Computing.** **A:** Distributed Cloud distributes public cloud services to different physical locations while being managed centrally. Edge Computing pushes computational data and processing power closer to the logical edge of the network (near the physical device/data source) to minimize latency.

**Q19: What is the difference between a Virtual Machine (VM) and a Container?** **A:** A VM virtualizes the underlying physical hardware and contains a full guest operating system. A container (like Docker) virtualizes the operating system kernel, sharing the host OS, making it much lighter, faster, and highly portable.

**Q20: What is DevOps, and what tool handles container orchestration?** **A:** DevOps is a collaborative cultural and professional methodology that unifies software development (Dev) and IT operations (Ops). **Kubernetes** is the industry-standard tool used for automated container orchestration, deployment, and scaling.

### **Unit VI: Planning & Ethics**

* **Q16: What is Classical Planning?**
It is the task of finding a sequence of actions to reach a goal in an environment that is assumed to be fully observable, deterministic, static, and finite.
* **Q17: What is Hierarchical Planning (HTN)?**
It is a planning method that recursively breaks down high-level abstract tasks into smaller, concrete sub-tasks until they become primitive, executable actions.
* **Q18: Progression vs. Regression Planning?**
Progression planning searches forward from the initial state to the goal, whereas regression planning searches backward from the goal to the initial state.

### **Unit I: Introduction & Intelligent Agents**

* **Q1: Difference between a rational agent and a human?**
A rational agent always acts to maximize its expected performance measure based on logic, whereas a human's actions can be influenced by emotions, biases, and imperfect reasoning.
* **Q2: What is PEAS?**
PEAS stands for Performance measure, Environment, Actuators, and Sensors; it is a framework used to completely define an intelligent agent's specification.
* **Q3: Fully vs. Partially Observable Environment?**
In a fully observable environment, the agent's sensors have access to the complete state of the world at any point, while in partially observable environments, some data is missing or hidden.

---

### **Unit II: Problem-Solving & Search**

* **Q4: What is a heuristic function?**
A heuristic function, $h(n)$, estimates the cost from the current node to the goal state, helping informed search algorithms find solutions much faster.
* **Q5: What is an admissible heuristic?**
A heuristic is admissible if it never overestimates the actual cost to reach the goal state (it is always optimistic).
* **Q6: Uninformed vs. Informed Search?**
Uninformed search explores the state space systematically without any domain knowledge, whereas informed search uses a heuristic to guide the search toward the goal.

---

### **Unit III: Adversarial Search and Games**

* **Q7: What is the Minimax strategy?**
Minimax is a decision-making algorithm for two-player games where one player tries to maximize their score while assuming the opponent will perfectly play to minimize it.
* **Q8: What is Alpha-Beta Pruning?**
It is an optimization technique for Minimax that cuts off branches in the game tree that do not affect the final decision, drastically reducing search time.
* **Q9: What is a Constraint Satisfaction Problem (CSP)?**
A CSP is a problem where the goal is to find a set of values for variables that satisfy a predefined set of conditions or limitations (constraints).

---

### **Unit IV: Knowledge and Logic**

* **Q10: What is a Knowledge-Based Agent?**
It is an agent that makes decisions by maintaining an internal database of facts and rules (Knowledge Base) and using logical inference to deduce new actions.
* **Q11: Propositional vs. First-Order Logic?**
Propositional logic deals with simple, whole facts that are true or false, while First-Order Logic is more expressive, modeling the world using objects, relations, and quantifiers ($\forall, \exists$).
* **Q12: Entailment ($\models$) vs. Inference ($\vdash$)?**
Entailment means a sentence is semantically true in all worlds where the knowledge base is true, while inference is the syntactic process of deriving that sentence using formal rules.
